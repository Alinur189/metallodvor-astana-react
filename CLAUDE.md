# metallodvor-astana-react

Сайт ТОО «МеталлоДвор» (Астана): React + Vite, деплой на Vercel.

## Общая память проекта

Память живёт в
`~/.claude/projects/-Users-alinur-Downloads-metallodvor-astana-react/memory/`.
Один факт — один файл. `MEMORY.md` в том же каталоге — индекс.

### Читать — в начале работы

Основная сессия получает `MEMORY.md` в контекст автоматически. **Подагенты
стартуют с чистого контекста и его не получают.** Поэтому любой подагент,
которому нужен контекст проекта (а не просто «найди строку в файле»),
начинает с чтения `MEMORY.md`, а затем — тех файлов памяти, чьи описания
относятся к задаче. Не полагайся на то, что «родитель уже всё рассказал»:
в промпте подагента ровно то, что в нём написано, и ничего больше.

### Писать — как только факт подтверждён

Записывай сразу, а не в конце задачи: фоновый агент может быть остановлен,
и всё, что он узнал, пропадёт.

Формат файла:

```markdown
---
name: <kebab-case-slug>
description: <одна строка — по ней решают, релевантен ли файл>
metadata:
  type: user | feedback | project | reference
---

<факт; для feedback/project ниже строки **Why:** и **How to apply:**>
```

Правила, обязательные при параллельной работе:

1. **Никогда не редактируй `MEMORY.md` руками.** Это единственный общий файл;
   два агента, делающие Read→Edit одновременно, затрут правки друг друга.
   Индекс пересобирает хук `.claude/memory-index.mjs` — он только дописывает
   недостающие строки и не трогает существующие.
2. **Один агент — свои файлы.** Прежде чем создавать новый файл, проверь,
   нет ли уже подходящего: дополняй его, а не плоди дубликаты.
3. **Правишь чужой файл — правь точечно.** Edit конкретной строки, а не
   Write целиком: параллельный агент мог дописать туда что-то минуту назад.
4. **Относительные даты — в абсолютные.** «на следующей неделе» через месяц
   бессмысленно. Сегодняшнюю дату бери из контекста сессии.
5. **Связывай факты** через `[[имя-другой-памяти]]`.

Не записывай то, что и так видно из кода, `git log` или этого файла.

### Возврат результата

Подагент, узнавший что-то долгоживущее, и записывает это в память, **и**
упоминает в своём финальном отчёте — родитель отчёт видит, а файлы
подагента отслеживать не обязан.

## Команды

- `npm run dev` — дев-сервер
- `npm run build` — сборка + пререндер (`scripts/prerender.mjs`)
- `npm run check` — линт и сборка, гонять перед коммитом
- `npm run images` — пережатие картинок (`scripts/optimize-images.mjs`), пишет в `public/images/`
